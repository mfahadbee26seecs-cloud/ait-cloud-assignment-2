# Sensor Readings Analysis Using Python

## Project Overview
This project involves developing a basic Python program to process and analyze a collection of sensor readings. The program uses built-in Python functions to determine the total number of readings, identify the highest and lowest values, and calculate their average.

## Sensor Data
The program uses the following five sensor readings:

22, 24, 26, 28, 30

These values are stored in a Python list and used to perform the required calculations.

## Program Output
After executing the program, the following results are displayed:

- **Total Readings:** 5
- **Minimum Reading:** 22
- **Maximum Reading:** 30
- **Average Reading:** 26.0

## Instructions to Run the Program
1. Download the `sensor_readings.py` file from this repository.
2. Launch Visual Studio Code (VS Code) on your computer.
3. Open the downloaded Python file in VS Code.
4. Ensure that Python is installed and properly configured.
5. Run the program by selecting the **Run Python File** option.
6. View the calculated results in the integrated terminal.

## Software and Platforms Used
- **Python:** Used to perform calculations and process sensor readings.
- **Visual Studio Code:** Used to write, edit, and execute the Python program.
- **GitHub:** Used to store and share the project files.

This assignment demonstrates the practical application of fundamental Python concepts, including lists, built-in functions, and basic numerical calculations. It also provides experience in creating, executing, and managing a simple Python project using VS Code and GitHub.
